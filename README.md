# 気温に合った服を着よう (Temperature Clothing Game)

## 概要

「気温に合った服を着よう」は、現在の気温に適した服を選びながらゴールを目指す3Dゲームです。

プレイヤーは画面上に表示される気温を参考に、ステージ上に配置された服を収集します。気温に適した服を選択すると有利に進めますが、不適切な服を選択すると移動速度が低下します。

環境情報を活用した意思決定をゲームシステムとして表現することを目的に制作しました。

---

## 制作背景

私はXR・AR技術やヒューマンインタフェースに興味を持っており、ユーザーが状況に応じて情報を認識し、判断し、行動する仕組みについて関心があります。

本作品では「気温」という環境情報をユーザーへ提示し、その情報を基に適切な服装を選択する体験をゲームとして実装しました。

日常生活における服装選択のプロセスをゲームに落とし込むことで、人とシステムのインタラクションについて学ぶことを目的として制作しました。

また、現在取り組んでいるAR/XR試着システム開発にもつながるテーマとして、服装と環境情報を組み合わせたコンテンツ設計を行いました。

---

## ゲーム内容

* ゲーム開始時に気温がランダムに決定される
* ステージ上に複数の服が配置される
* プレイヤーは気温に適した服を探して取得する
* 取得した服はTOP・BOTTOMアイコンとして画面上に表示される
* 服によって移動速度が変化する
* 気温に適した服装でゴールを目指す

## 実装した機能

### 気温システム

ゲーム開始時にランダムな気温を設定し、その気温に適した服を選択するゲームルールを実装しました。

### 服データ管理

ScriptableObjectを利用し、服ごとの情報をデータとして管理しています。

管理項目例

* 服の名称
* 服の種類（TOP / BOTTOM）
* 移動速度補正値
* 適正気温範囲

### プレイヤーステータス変更

取得した服に応じてプレイヤーの移動速度をリアルタイムに変更しています。

### 装備システム

取得した服を現在の装備として管理し、装備内容に応じてプレイヤーの状態へ反映しています。

### UI表示

現在の気温、プレイヤーの移動速度、重量状態（WEIGHT）をリアルタイムに表示しています。

また、取得した服をTOP・BOTTOMアイコンとして表示し、現在装備している服装を視覚的に確認できるようにしました。

### ゴール判定

プレイヤーがゴール地点へ到達した際、選択した服が現在の気温に適しているかを判定する機能を実装しました。

---

## 工夫した点

### ヒューマンインタフェースを意識した設計

プレイヤーは表示された気温情報を確認し、その情報を基に服を選択します。

さらに、取得した服をTOP・BOTTOMアイコンとして表示することで、現在の装備状況を一目で把握できるようにしました。

単純なアイテム収集ではなく、

「情報の提示」
→「状況の理解」
→「意思決定」
→「行動」
→「結果のフィードバック」

というヒューマンインタフェースの流れをゲームシステムへ取り入れています。

### 環境情報とゲームプレイの連携

気温という環境要因をゲームルールへ組み込み、プレイヤーが状況に応じて判断する体験を設計しました。

### データ駆動型の実装

ScriptableObjectを利用して服データとゲームロジックを分離し、拡張性と保守性を向上させました。

### リアルタイムフィードバック

服の選択結果を移動速度へ即座に反映することで、プレイヤーが選択の影響を直感的に理解できるよう工夫しました。

### 視認性を考慮したUI設計

気温・移動速度・重量状態・現在の装備を画面上へ常時表示することで、プレイヤーが必要な情報を素早く把握できるよう設計しました。
