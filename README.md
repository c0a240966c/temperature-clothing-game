# 気温に合った服を着よう

## 概要

「気温に合った服を着よう」は、現在の気温に適した服を選びながらゴールを目指す3Dゲームです。

画面右上に表示される気温を参考に、ステージ上に配置された服を集めます。気温に適した服を選ぶことで有利に進める一方、不適切な服を選ぶと移動速度が低下します。

服装選びという日常的な行動をゲームシステムとして表現することを目的に制作しました。

---

## 制作背景

私はXR・ARを活用した試着システムやファッション関連技術に興味を持っています。

本作品では、「服選び」と「環境情報（気温）」を組み合わせることで、ユーザーが状況に応じて判断するゲーム体験を設計しました。

将来的にはAR/XR試着システムの開発にも応用できるアイデアとして考えています。

---

## ゲーム内容

* ランダムな気温が表示される
* ステージ上に複数の服が配置される
* 気温に適した服を取得する
* 不適切な服を取得すると移動速度が低下
* 制限時間内にゴールを目指す

## 実装した機能

### 気温システム

ゲーム開始時に気温を設定し、プレイヤーはその気温に適した服を選択する必要があります。

### 服データ管理

ScriptableObjectを利用し、服ごとの情報を管理しています。

* 服の名前
* 適正気温
* 速度補正値

などをデータとして保持しています。

### プレイヤーステータス変更

取得した服に応じてプレイヤーの移動速度をリアルタイムで変更しています。

### UI表示

現在の気温やプレイヤーの状態を画面上に表示し、状況を把握しやすくしています。

## 工夫した点

* ScriptableObjectを利用して服データを管理し、拡張しやすい構成にした

* データと処理を分離し、保守性を意識して実装した
* プレイヤーが状況に応じて判断するゲーム性を取り入れた
